# Registro de Usuários

Sistema de gerenciamento de usuários com React, Vite e Node.js. Cadastre, liste e exclua usuários via API.

**Stack:** React, Vite, Axios · Node.js, Express, MongoDB, Prisma

**Requisitos:** Node.js v16+, MongoDB

```bash
git clone https://github.com/Akynovia/cadastro-de-usuarios.git

cd API && npm install && cp .env.example .env && npm start
cd Frontend && npm install && npm run dev
```

Frontend → http://localhost:5173  
API → http://localhost:3333
